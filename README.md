
# Credit Card Fraud Detection Using Machine Learning

## Project Description

Credit Card Fraud Detection is a Machine Learning
project developed using Python.

The system identifies potentially fraudulent
transactions using historical transaction data.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Logistic Regression
- Streamlit
- Matplotlib
- Seaborn

## Algorithms

1. Logistic Regression
2. Random Forest Classifier

## Project Features

- Transaction data preprocessing
- Fraud classification
- Model training
- Model evaluation
- Fraud probability prediction
- Interactive web application

## Dataset

Download the Credit Card Fraud Detection dataset:

https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

Place creditcard.csv inside the data folder.

## Installation

pip install -r requirements.txt

## Generate Demo Data

python generate_demo_data.py

## Train Model

python train.py

## Run Application

streamlit run app.py
